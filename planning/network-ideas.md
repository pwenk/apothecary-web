# 12 network ideas

Round 3, 22 Sep 2026. Follows `interlinking-ideas.md` (ideas A–F).

**The question:** how do the articles link up into a network, so that one page leads to the next for a good reason?
**The method:** the same twelve thinking skills from `structure-concepts.md`, one idea each. Then the two website skills (Top-Design and Frontend Design) score them, as before.

> Substances, articles and claims in the sketches are placeholders to show the shape. Anything medical needs a cited source before it goes live.

**All ideas rest on the same foundation:** the shared labels from `interlinking-ideas.md` (substance, situation, phase, mechanism, claim). Build that once and every idea below becomes one more way to draw it.

---

## 1 · The Seating Plan 🍷
**Skill: Drunk Claude** · move: *"what if but wrong"*. What if substances were guests at a dinner party who gossip about each other?

Every substance gets relationships in plain words: **gets on with** (works well together), **don't seat together** (clash), **old flame** (advice that used to link them, and changed). The network page is a round table seating plan. Tap a guest and their friends light up while their clashes turn red.

```
┌──────────────────────────────────────────────────────────────────┐
│  THE SEATING PLAN                       tap a guest to see who   │
│                                         they get on with         │
│                  ( Vitamin C )                                   │
│          ( Zinc )             ( Orange juice )                   │
│                                                                  │
│      ( Honey )     ╭──────────────╮     ( Doxycycline )          │
│                    │    TABLE     │           ┊ ✗ don't seat     │
│      ( Gelatin )   ╰──────────────╯     ( Milk / calcium )       │
│                                                                  │
│          ( Aspirin ) ─ ✗ ─ ( Ibuprofen )                         │
│                  ( Paracetamol )                                 │
│                                                                  │
│  ── gets on with    ✗ don't seat together    ┈ old flame         │
└──────────────────────────────────────────────────────────────────┘
```
**Good:** makes interactions memorable and a bit funny. **Risk:** the joke has to stay light so clashes still read as serious.

## 2 · Pull a Thread 🧵
**Skill: Lateral Thinking** · Po: *"the site has no links at all."* The principle it gives: readers make the links themselves.

Every article ends with three loose threads, each of a different kind: **same mechanism**, **same origin**, **same era**. Every thread you pull adds a knot to a string at the bottom of the screen. Your trail becomes a web address you can share: *aspirin → willow bark → salicylates in food → …*

```
┌───────────────────────────────────────────────────────────┐
│  … end of Aspirin                                         │
│                                                           │
│  Pull a thread:                                           │
│   ⟿ same mechanism   Omega-3 and blood clotting           │
│   ⟿ same origin      Other medicines from tree bark       │
│   ⟿ same era         1890s: the first factory drugs       │
│                                                           │
│  Your thread ●───●───●───○                                │
│              Aspirin  Willow  Salicylates  ?              │
│                                          [ Share trail ]  │
└───────────────────────────────────────────────────────────┘
```
**Good:** curiosity-driven and cheap to build. **Risk:** needs at least three good threads per article.

## 3 · The Back-of-Book Index 📖
**Skill: Oblique Strategies** · card drawn: *"Use an old idea."* The oldest network tool in print is the index at the back of a book.

One page with four indexes side by side: **Substances · Situations · Body parts · People** (Anna Atkins, Ray Peat, Bayer…). Each entry lists page references as article section links, like *Aspirin 12, 14–15*. It is dense, fast and very apothecary.

```
┌───────────────────────────────────────────────────────────────────┐
│  INDEX                          A B C D E F G … (letter jump)     │
│                                                                   │
│  Substances           Situations          Body                    │
│  ─────────            ──────────          ────                    │
│  Aspirin  001·2, 3    Cold & flu 001·4,   Blood  001·2            │
│    and children 001·4   004·3, 00x·1      Gut    003·4, 005·2     │
│    and ibuprofen 001·3 Poor sleep 002·3,  Joints 005·1–3          │
│  Collagen see Gelatin   005·4             Thyroid 002·1–2         │
│  Doxycycline 003·1–4  After antibiotics                           │
│                         003·4                                     │
│                                                                   │
│  People: Anna Atkins 1843 · Felix Hoffmann 001·1 · Ray Peat 002   │
└───────────────────────────────────────────────────────────────────┘
```
**Good:** the fastest way to find anything, and it matches the herbarium theme. **Risk:** looks dull unless the type is beautiful.

## 4 · The Transit Map 🚇
**Skill: Creative Director** · move: *bisociation* (joining two unrelated worlds): a pharmacy crossed with a subway map.

Each **situation is a line** (Cold line, Sleep line, Gut line, Heart line). Each **substance is a station**. Substances that help in more than one situation become **interchange stations**. Stations on a line appear in phase order: prevent → treat → recover.

```
┌─────────────────────────────────────────────────────────────────────┐
│  APOTHECARY LINES                                                   │
│                                                                     │
│  ━━ Cold    ●━━━━━━●━━━━━━━◉━━━━━━━●━━━━━━●                          │
│          Hand-  Vit C   Honey   Zinc   Rest                         │
│          washing          ┃                                         │
│  ━━ Sleep       ●━━━━━━━━━◉━━━━━━━━●                                │
│               Gelatin    ┃     Dark room                            │
│                          ┃                                          │
│  ━━ Gut      ●━━━━━━━━━━━◉━━━━━━━━●━━━━━━●                           │
│           Carrot      Orange   After   Doxycycline                  │
│           salad       juice    antibiotics                          │
│                                                                     │
│  ◉ interchange: helps on more than one line                         │
└─────────────────────────────────────────────────────────────────────┘
```
Phone: one line at a time, drawn vertically, with the other lines as tabs.

**Good:** everyone already knows how to read one, it looks striking, and it's a perfect "spend boldness in one place" page. **Risk:** hand-placing the stations takes real design work, since automatic layouts look messy.

## 5 · Earned Links 🔓
**Skill: TRIZ** · the trade-off: *more links help discovery, but they clutter reading.* The fix is to separate them **in time**.

Links stay hidden while you read a section. When you reach the end of it, its cross-links slide into the margin: *"Now that you know how aspirin thins the blood → the same trick in omega-3."* Nothing interrupts you mid-sentence, and every link arrives just when it makes sense.

```
┌─────────────────────────────────────────┬──────────────────────────┐
│  How it thins the blood                 │                          │
│  … for the platelet's whole life.       │                          │
│  ▔▔▔▔▔▔▔▔▔▔▔▔▔ (you reach here) ▔▔▔▔▔▔▔ │  ✦ unlocked              │
│                                         │  Same trick, from fish:  │
│  Who should skip it                     │  Omega-3 → §2            │
│  Children with a viral illness …        │  (1 of 3 links found)    │
└─────────────────────────────────────────┴──────────────────────────┘
```
**Good:** calm reading, with a small reward for finishing. **Risk:** hiding links can annoy skimmers, so add a "show all links" switch.

## 6 · My Shelf 🧺
**Skill: Flux** · assumption flipped: *"a reader wants one substance"* becomes *"a reader arrives with a cupboard full of them."*

Tick what you have at home. The site draws the network between **your** things only: which work together, which clash, which need hours apart, and which articles explain why. The selection lives in the web address, so nothing is stored about you.

```
┌───────────────────────────────────────────────────────────────┐
│  What's on your shelf?                                        │
│  [✓] Aspirin  [✓] Orange juice  [✓] Doxycycline  [ ] Gelatin │
│  [ ] Zinc     [ ] Honey         [+ add]                       │
│                                                               │
│   Aspirin ─────────── Orange juice      nothing noted         │
│      │                    │                                   │
│      └──── ? ─────── Doxycycline ─ ⏱ ─ Calcium-rich OJ        │
│                                     keep apart (see §3)       │
│                                                               │
│  ⏱ 1 timing note   ✗ 0 clashes   ? 1 pair not covered yet     │
│  "Not covered" means we haven't written about it, not "safe". │
└───────────────────────────────────────────────────────────────┘
```
**Good:** the most personally useful idea here. **Risk:** the most sensitive too. It needs careful sourcing and the "not covered ≠ safe" rule.

## 7 · The Abstraction Ladder 🪜
**Skill: Creative Thinking for Research** · move: *abstraction laddering* (climb from the specific to the general and back).

Every article has a small ladder beside the title. Climb **up** and you reach wider groups, where other substances live: *aspirin → pain relievers from plants → things that calm inflammation*, which also includes omega-3 and ginger. Climb **down** and you reach the detail: *salicylic acid → the COX enzyme*. Each rung is a hub page.

```
┌────────────────────────────────────┐
│  ▲ Things that calm inflammation   │  ← 7 substances
│  │   (aspirin, omega-3, ginger …)  │
│  ▲ Pain relievers from plants      │  ← 3 substances
│  │                                 │
│  ● ASPIRIN  (you are here)         │
│  │                                 │
│  ▼ Salicylic acid                  │
│  ▼ Switching off COX enzymes       │  ← shared with ibuprofen
└────────────────────────────────────┘
```
**Good:** teaches how things are related, not only *that* they are. **Risk:** writing good rungs takes thought for each article.

## 8 · The Family Tree 🌳
**Skill: claude-brainstorm** · technique: *analogy hunt*. Medicines have ancestry, just like people.

A genealogy of origins: **willow → salicin → aspirin**, **soil bacteria → tetracyclines → doxycycline**, **cow bone and skin → collagen → gelatin**. Food and drug branches share roots. This fits the herbarium ("every remedy was once a living thing") better than any other idea here.

```
┌─────────────────────────────────────────────────────────────────┐
│  WHERE IT ALL CAME FROM                                         │
│                                                                 │
│     PLANTS                  MICROBES              ANIMALS       │
│    ┌──┴───────┐                │                     │          │
│  Willow    Orange tree     Soil bacteria          Cattle        │
│    │           │               │                     │          │
│  Salicin   Vitamin C      Tetracyclines          Collagen       │
│    │           │               │                     │          │
│  ASPIRIN   ORANGE JUICE   DOXYCYCLINE            GELATIN        │
│  1897                     1967                                  │
└─────────────────────────────────────────────────────────────────┘
```
**Good:** true to the site's identity, and every new article slots into a branch. **Risk:** only covers origin. It's one kind of link, so it can't be the only network.

## 9 · Glossary Hubs 🔤
**Skill: via negativa** · removed: *hand-picked "related articles".* What's left are the words articles already share.

Key terms such as *platelet*, *collagen*, *COX enzyme* and *gut flora* get a subtle underline. Each term has a small page with a two-line definition and **every article that uses it**. The network builds itself as you write. You add no links by hand, and nothing goes stale.

```
Article text:
  … aspirin blocks the C̲O̲X̲ ̲e̲n̲z̲y̲m̲e̲ in p̲l̲a̲t̲e̲l̲e̲t̲s̲ …
                            │
                            ▼  (tap)
                 ┌──────────────────────────────┐
                 │ COX enzyme                   │
                 │ Makes the signals for pain   │
                 │ and swelling.                │
                 │ Mentioned in: Aspirin §2 ·   │
                 │ Ibuprofen §1 · Omega-3 §3    │
                 └──────────────────────────────┘
```
**Good:** the cheapest idea here, and it grows automatically. **Risk:** too many underlines look like Wikipedia. Mark only the first mention per article.

## 10 · The Body Map 🫀
**Skill: first principles** · what *is* a link, at bottom? Two substances are connected when they act on the same part of you.

A simple outline of a body with hubs: brain, thyroid, blood, gut, joints and skin. Substances connect to the parts they affect. Tap *gut* and you see doxycycline, raw carrot, orange juice and the after-antibiotics path.

```
┌───────────────────────────────────────────────────────────┐
│          ◯  brain ········· Ray Peat (sleep, stress)      │
│         ─┼─ thyroid ······· Ray Peat                      │
│          │  blood ········· Aspirin                       │
│        ┌─┴─┐                                              │
│        │   │ gut ·········· Doxycycline · Carrot · OJ     │
│        └───┘                                              │
│        │   │ joints ······· Gelatin                       │
│        ┘   └                                              │
│  Tap a body part to see everything that acts on it.       │
└───────────────────────────────────────────────────────────┘
```
**Good:** visual, instantly understood, and it works for readers who don't know substance names. **Risk:** an anatomy drawing can look clinical, so it has to be drawn in the herbarium style.

## 11 · The Day Wheel 🕰️
**Skill: robertguss brainstorm** · perspective shift: look through **time of day** instead of through topics.

A 24-hour wheel with substances placed at the hours when articles say they matter: orange juice at breakfast, gelatin in the evening, doxycycline with a glass of water and not lying down. It ties straight into the sun-synced colours, because the wheel's current hour matches the page colour ☀️→🌙

```
                     12:00
                       │
          ☀  ·  ·  ·   │   ·  ·  ·  ◐
       Orange juice    │         Doxycycline
        (breakfast)    │     (upright, with water)
   06:00 ──────────────●────────────── 18:00
                       │   ← now: 17:40, sunset in 1h
          ☾  ·  ·  ·   │   ·  ·  ·  ☾
                       │        Gelatin
                       │     (evening, Ray Peat)
                     00:00
```
**Good:** a delightful, one-of-a-kind idea that fits the sun theme. **Risk:** only some claims have a time of day, so it's a side view and can't be the main network.

## 12 · The Argument Map ⚖️
**Skill: borghei brainstorm-ideas** · *"How might we show where experts disagree without taking sides?"*

Claims become nodes, joined by **supports**, **contradicts** or **replaced by** links. Ray Peat's ideas sit next to mainstream views with the evidence marks visible. Advice that reversed (aspirin, 2022) shows as a crossed-out node with an arrow to what replaced it.

```
┌───────────────────────────────────────────────────────────────────┐
│  WHERE PEOPLE DISAGREE                                            │
│                                                                   │
│   ◐ "Sugar supports the         ✗ contradicts   ● "Added sugar    │
│      thyroid" (Ray Peat) ───────────────────────  raises risk     │
│          │                                        of …" (WHO)     │
│          │ supports                                               │
│   ○ "Orange juice beats                                           │
│      water for stress"                                            │
│                                                                   │
│   ✗ old: "Daily aspirin for over-60s" ──replaced by (2022)──▶ ● new advice │
└───────────────────────────────────────────────────────────────────┘
```
**Good:** honest, and made for a site that already covers Ray Peat. **Risk:** it's the hardest to keep fair, so every node needs a source.

## Recommendation

Five ideas tie at 15, and they do different jobs, so they combine instead of competing:

- **Plumbing (invisible, cheap):** Glossary Hubs (9) + the Back-of-Book Index (3). Both come out of the same term list, so the network grows by itself as articles are written.
- **The one bold page:** the **Transit Map** (4), with situation lines that match the Care Paths (Idea A). One boldness budget, spent here.
- **Identity:** the **Family Tree** (8) as the About or Origins page, because it *is* the herbarium idea.
- **Later, once the sun work settles:** the **Day Wheel** (11), a small wheel in the corner that shows the hour and what matters at it.
- **Park until the sources are solid:** My Shelf (6) and the Argument Map (12). They're the most useful and the most sensitive, and a wrong line would do real harm.

Together with round 2: Pad Article (C) + margin notes (B) for articles, Care Paths (A) for situations, the Transit Map as their overview, and the Food ↔ Drug Map (D) kept as Explore.
